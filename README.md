# Blooming Flowers — For Shweta 🌷

A romantic, responsive mini website where flowers grow and bloom when the visitor taps the button.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in any modern browser.
3. Tap **Grow our garden** to animate the stems, leaves, blossoms, and falling petals.

No build tools or installation are required. Google Fonts are loaded online; the page falls back to system fonts if offline.

## Customize
- Edit the message and text in `index.html`.
- Change colors and layout in `style.css`.
- Change the flower animation and petal effects in `script.js`.
